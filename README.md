# NovaAI

Cinematic landing page for **novaai** — *Today AI Aligns With Bold Dreams*.

Stack: React, TypeScript, Vite, Tailwind CSS, lucide-react.

## Local

```bash
npm install
npm run dev
```

Open the printed local URL. Scroll to scrub the full-bleed hero video.

```bash
npm run build
npm run preview
```
